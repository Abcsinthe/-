# 双月形数据集的神经网络分类器

这个项目实现了一个简单的神经网络，用于分类一个形状像两个交错月亮的合成数据集。神经网络使用 NumPy 构建，采用 sigmoid 激活函数、交叉熵损失和 L2 正则化。

## 特性

- 生成二维双月形数据集。
- 实现一个具有一个隐藏层的前馈神经网络。
- 使用梯度下降训练模型。
- 可视化训练后的决策边界。

## 使用方法
生成数据：使用 sklearn.datasets 中的 make_moons 函数生成数据。

定义神经网络：神经网络包括：

- 输入层
- 一个隐藏层
- 输出层（使用 softmax 进行分类）
- 训练模型：build_model 函数初始化权重和偏置，并使用训练数据集训练模型。

可视化结果：训练完成后，使用 matplotlib 绘制决策边界。

# 不同神经元数量的决策边界可视化

## 特性

- 生成二维双月形数据集。
- 实现一个具有一个隐藏层的前馈神经网络。
- 可视化不同隐藏层神经元数量下的决策边界。
